# Transform

## 핵심 개념

- 모든 게임오브젝트가 기본으로 가지는 컴포넌트 — 삭제 불가
- 오브젝트의 **위치, 회전, 크기** 와 **부모-자식 관계** 를 담당
- Unity의 모든 공간 처리가 Transform에서 시작됨

## 주요 프로퍼티

### 위치 (Position)

| 프로퍼티        | 설명                          |
| --------------- | ----------------------------- |
| `position`      | 월드 좌표 기준 위치 (Vector3) |
| `localPosition` | 부모 오브젝트 기준 상대 위치  |

### 회전 (Rotation)

| 프로퍼티           | 설명                                |
| ------------------ | ----------------------------------- |
| `rotation`         | 월드 기준 회전값 (Quaternion)       |
| `localRotation`    | 부모 기준 상대 회전 (Quaternion)    |
| `eulerAngles`      | 월드 기준 회전을 각도(0~360)로 표현 |
| `localEulerAngles` | 부모 기준 상대 회전을 각도로 표현   |

Quaternion은 3D 회전을 수학적으로 표현한 것 — 직접 다루기 어렵기 때문에 eulerAngles로 접근하는 경우가 많음

### 크기 (Scale)

| 프로퍼티     | 설명                                            |
| ------------ | ----------------------------------------------- |
| `localScale` | 부모 기준 상대 크기. Vector3(1,1,1)이 원본 크기 |
| `lossyScale` | 월드 기준 실제 크기 (읽기 전용)                 |

### 방향 벡터

| 프로퍼티  | 설명                          |
| --------- | ----------------------------- |
| `forward` | 오브젝트가 바라보는 방향 (+Z) |
| `right`   | 오브젝트의 오른쪽 방향 (+X)   |
| `up`      | 오브젝트의 위쪽 방향 (+Y)     |

오브젝트가 회전하면 이 방향 벡터도 같이 회전 — 자신이 바라보는 방향으로 이동할 때 활용

### 부모-자식 관계

| 프로퍼티     | 설명                |
| ------------ | ------------------- |
| `parent`     | 부모 Transform 참조 |
| `childCount` | 자식 오브젝트 수    |

## 주요 메서드

### 이동

- `Translate(Vector3)` — 현재 위치에서 상대적으로 이동
- `position =` — 절대 좌표로 순간 이동

### 회전

- `Rotate(Vector3)` — 현재 회전에서 상대적으로 회전
- `LookAt(Transform)` — 특정 대상을 바라보도록 회전
- `RotateAround(point, axis, angle)` — 특정 점을 중심으로 공전

### 부모-자식 관계

- `SetParent(Transform)` — 부모 오브젝트 변경
- `GetChild(index)` — 인덱스로 자식 접근
- `Find("이름")` — 이름으로 자식 탐색 (직계 자식만)

## 월드 좌표 vs 로컬 좌표

```
부모 오브젝트 position = (10, 0, 0)
자식 오브젝트 localPosition = (2, 0, 0)

자식의 실제 월드 position = (12, 0, 0)
```

- `position` — 씬 전체 기준 실제 위치
- `localPosition` — 부모를 원점으로 한 상대 위치
- 부모가 이동하면 자식의 `position`은 바뀌지만 `localPosition`은 그대로

## 부모-자식 구조 활용

```
캐릭터 (부모)
├─ 몸통 스프라이트
├─ 무기 (자식) ← 캐릭터가 이동하면 무기도 같이 이동
└─ HP바 UI (자식) ← 항상 캐릭터 위에 표시
```

부모가 움직이면 자식도 같이 움직임 — 복합 오브젝트 구성에 핵심

## 게임 개발 관점에서

- **캐싱 권장**: `transform`은 자주 접근하는 프로퍼티라 변수에 캐싱해두면 성능에 좋음. 단 Unity 최신 버전에서는 자동 최적화되어 있어 예전만큼 중요하지 않음
- **2D에서 z축**: 2D 게임에서 position.z는 렌더링 순서(앞/뒤)를 결정. 숫자가 작을수록 앞에 그려짐
- **localScale 주의**: 부모의 Scale이 (2, 2, 1)이고 자식의 localScale이 (1, 1, 1)이면 자식의 실제 크기는 (2, 2, 1). 부모 Scale 변경 시 자식에 영향

## 의문점 / 더 알아볼 것

- Quaternion 수학적 개념 — 짐벌락(Gimbal Lock) 문제와 Quaternion이 이를 해결하는 방식
- `TransformPoint` / `InverseTransformPoint` — 월드 ↔ 로컬 좌표 변환 메서드
- RectTransform — UI 전용 Transform. Canvas 안의 UI 요소는 이걸 사용
