# 가산기 (Adder)

## 핵심 개념

- **가산기(Adder)**: ALU 안에서 덧셈을 수행하는 디지털 회로
- CPU 연산의 가장 기본 단위 — 뺄셈, 곱셈, 나눗셈도 결국 가산기를 기반으로 구현됨
- 모든 산술 연산의 핵심 하드웨어

## 반가산기 vs 전가산기

```
반가산기 (Half Adder) — 1비트 2개를 더함
  입력: A, B
  출력: Sum(합), Carry(올림)

  A=0, B=0 → Sum=0, Carry=0
  A=0, B=1 → Sum=1, Carry=0
  A=1, B=0 → Sum=1, Carry=0
  A=1, B=1 → Sum=0, Carry=1  ← 올림 발생

전가산기 (Full Adder) — 이전 자리 올림(Carry)까지 포함
  입력: A, B, Cin(이전 Carry)
  출력: Sum, Cout(다음 Carry)
```

## 실제 덧셈 동작 (8bit 예시)

```
  0000 1010  (10)
+ 0000 0110  ( 6)
───────────
  0001 0000  (16)

각 자리를 전가산기가 처리, 올림(Carry)을 다음 자리로 전달
```

## 가산기로 뺄셈을 처리하는 방법

뺄셈 전용 회로 없이 가산기 + 보수기로 해결

```
10 - 6 = ?

① 6의 2의 보수 계산 (보수기 역할)
   6 = 0000 0110
   1의 보수 = 1111 1001
   2의 보수 = 1111 1010  (= -6)

② 가산기로 덧셈
   0000 1010 (10)
+  1111 1010 (-6)
────────────
   0000 0100 (4)  ← 올림 발생하지만 무시
```

## 게임 개발 관점에서

- 직접 다룰 일 없음
- **덧셈이 뺄셈보다 빠르지 않은 이유**: 현대 CPU에서 가산기는 이미 최적화되어 있고 보수 변환도 하드웨어로 처리되어 덧셈과 뺄셈의 속도 차이가 없음
- **정수 오버플로우**: 가산기에서 최상위 비트에서 올림(Carry)이 발생하면 Carry Flag가 1이 됨 → `checked` 키워드와 연결
