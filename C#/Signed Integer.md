# 부호 있는 정수 (Signed Integer)

## 핵심 개념

- **부호 있는 정수**: 음수와 양수를 모두 표현하는 정수 타입
- 가장 높은 비트(MSB)를 부호처럼 쓰고, 음수는 **2의 보수** 방식으로 저장함. [[Complementer]] 참고
- C# 키워드는 .NET 타입의 별칭임. `int`와 `System.Int32`는 완전히 같은 타입임

| 키워드 | .NET 타입 | 크기 | 범위 |
| --- | --- | --- | --- |
| `sbyte` | `SByte` | 1바이트 | -128 ~ 127 |
| `short` | `Int16` | 2바이트 | -32,768 ~ 32,767 |
| `int` | `Int32` | 4바이트 | 약 -21억 ~ 21억 |
| `long` | `Int64` | 8바이트 | 약 -922경 ~ 922경 |

## 음수 쪽이 하나 더 큼

- `sbyte`는 -128부터 127까지임. 음수가 하나 더 많음
- 2의 보수에서는 0이 하나뿐이라, 0을 양수 쪽에 포함하면 양수 자리가 하나 모자라기 때문임

```
0111 1111 =  127   (양수 최댓값)
0000 0000 =    0
1111 1111 =   -1
1000 0000 = -128   (음수 최솟값, 대응하는 +128이 없음)
```

- 그래서 `Math.Abs(int.MinValue)`는 결과를 표현할 수 없어 **예외가 발생함**

## 오버플로

- 범위를 넘으면 기본적으로 **예외 없이 반대쪽 끝으로 넘어감**

```
int.MaxValue + 1  →  int.MinValue
2,147,483,647 + 1 → -2,147,483,648
```

| 컨텍스트 | 동작 |
| --- | --- |
| 기본 (`unchecked`) | 조용히 넘어감. 에러 없음 |
| `checked` | `OverflowException` 발생 |
| 상수끼리의 계산 | 컴파일 단계에서 에러로 잡힘 |

- 실행 중 값으로 계산하면 컴파일러가 잡아주지 못하므로, 오버플로 위험이 있는 곳은 `checked`로 감싸거나 더 큰 타입을 써야 함

## 산술 승격

- `sbyte`, `short`끼리 연산하면 결과는 **`int`**가 됨
- 작은 타입끼리 더해도 작은 타입으로 돌아오지 않으므로, 다시 담으려면 명시적 캐스팅이 필요함
- CPU가 `int` 크기로 계산하는 것이 자연스럽기 때문에 정해진 규칙임

## 정수 나눗셈

- 정수끼리 나누면 결과도 정수이고, 소수점 아래는 **0 방향으로 버림**
- `7 / 2`는 3, `-7 / 2`는 -3
- 비율을 계산하려다 결과가 0이 되는 실수가 흔함. 한쪽을 `float`로 바꿔 계산할 것

## 어떤 타입을 고르나

| 상황 | 선택 |
| --- | --- |
| 특별한 이유가 없음 | `int` |
| 21억을 넘을 수 있음 (누적 점수, 시간 틱, 큰 재화) | `long` |
| 대량 저장이나 네트워크 전송에서 크기를 줄여야 함 | `short`, `sbyte` |

- 작은 타입이 계산까지 빠른 것은 아님. 연산은 `int`로 승격되어 처리됨
- 작은 타입의 이점은 **메모리와 전송량**에만 있음

## 게임 개발 관점에서

**재화와 데미지 오버플로**

- 골드나 데미지가 21억을 넘는 순간 음수로 바뀌는 버그가 실제로 자주 일어남
- 성장형·방치형 게임은 처음부터 `long`이나 더 큰 수 표현 방식을 고려해야 함
- 곱셈이 들어가는 계산(데미지 × 배율 × 치명타)은 중간 결과에서 먼저 넘칠 수 있음

**데이터 크기 최적화**

- 타일 종류, 아이템 개수처럼 범위가 작은 값을 대량으로 저장할 때 `short`나 `byte`로 줄이면 메모리가 크게 줄어듦
- 단 계산할 때마다 캐스팅이 필요해지므로, 저장용과 계산용을 구분해서 쓰는 것이 좋음

## 의문점 / 더 알아볼 것

- `checked` 컨텍스트를 프로젝트 전체에 거는 컴파일 옵션
- `BigInteger` — 크기 제한 없는 정수와 그 비용
- `nint` — 플랫폼 크기에 맞춰지는 정수
- 정수 대신 `double`로 큰 수를 다룰 때의 정밀도 문제
- 짝을 이루는 [[Unsigned Integer]]와의 혼용 규칙
